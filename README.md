## Опис компонентів:

Серверна частина (Python + Flask)
Імпорт бібліотек:

Flask: веб-фреймворк для створення веб-додатків.
json: для роботи з JSON-форматом.
threading: для роботи з потоками.
time: для роботи з часом.
WebSocketApp: для роботи з WebSocket з'єднаннями.
Ініціалізація Flask додатку:

Створюється об'єкт Flask, який буде використовуватися для обробки HTTP-запитів.
Константи:

DATA_EXPIRATION: час життя даних у секундах (4 секунди).
SPEED_OF_LIGHT: швидкість світла (300,000 км/с).
Глобальні змінні:

data_points: список для зберігання точок даних.
Допоміжні функції:

calculate_distance(sent, received): розраховує відстань на основі часу передачі сигналу.
calculate_position(...): виконує трилатерацію для визначення позиції об'єкта на основі координат і радіусів супутників.
WebSocket обробники:

on_message(ws, message): обробляє отримані повідомлення через WebSocket, оновлює або додає нові точки даних.
on_open(ws), on_close(ws), on_error(ws): обробники для відкриття, закриття та помилок WebSocket.

Flask маршрути:

@app.route('/'): обробляє запит на головну сторінку, повертає HTML-шаблон.
@app.route('/config', methods=['POST']): обробляє запит на оновлення конфігурації системи.
@app.route('/data'): повертає дані про позиції об'єкта, якщо є достатня кількість точок.
@app.after_request: додає CORS заголовки до всіх відповідей.
Запуск додатку:

start_websocket(): запускає WebSocket клієнт у окремому потоці.
Запускається Flask сервер.
Клієнтська частина (HTML + CSS + JavaScript)

HTML:

Створює структуру веб-сторінки, включаючи заголовок, контейнер для графіка та форму для налаштувань.
